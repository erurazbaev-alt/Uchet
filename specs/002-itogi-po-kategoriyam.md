# Итоги по категориям

## Для кого и зачем

Для человека или семьи, которые хотят понимать не только общий размер расходов, но и распределение трат по основным категориям за текущий месяц.

## Что должно быть

- Под общим итогом за текущий месяц показываются отдельные суммы по категориям:
  - Еда;
  - Транспорт;
  - Дом;
  - Другое.
- В расчёт входят только траты текущего календарного месяца.
- Итоги пересчитываются сразу после добавления или удаления траты.
- Категория без трат отображается с суммой `0 ₸`.
- Суммы показываются в целых тенге с пробелами между тысячами.
- Фильтр списка «День / Неделя / 14 дней / Месяц / Все» не влияет на итоги по категориям: они всегда относятся к текущему месяцу, как и общий итог.

## Примеры

- Еда `5 000 ₸` и `2 500 ₸`, Транспорт `3 000 ₸` → Еда `7 500 ₸`, Транспорт `3 000 ₸`, Дом `0 ₸`, Другое `0 ₸`.
- Трата «Дом» за прошлый месяц остаётся в списке, но не входит в итог категории «Дом» за текущий месяц.
- После удаления траты на еду `2 500 ₸` итог категории «Еда» уменьшается на `2 500 ₸`.

## Ограничения

- Только HTML, CSS и JavaScript без библиотек и внешних ресурсов.
- Данные берутся из уже сохранённых в localStorage трат; отдельное хранилище для итогов не создаётся.
- Интерфейс на русском языке.
- Блок должен удобно отображаться на телефоне шириной 375px.
- Нельзя показывать дробные суммы или `NaN`.
- Существующие добавление, удаление, список, фильтрация и общий итог не должны сломаться.

## Готово, когда

- Под общим итогом видны четыре категории и их суммы за текущий месяц.
- Сумма четырёх категорий равна общему итогу за текущий месяц.
- После добавления или удаления траты нужная категория и общий итог обновляются без перезагрузки.
- Траты прошлого месяца не учитываются.
- Категории без расходов показывают `0 ₸`.
- После F5 итоги правильно восстанавливаются из сохранённых трат.
- Блок читаем и удобен на ширине 375px.
