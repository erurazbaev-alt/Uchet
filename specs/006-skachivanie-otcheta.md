# Скачивание отчёта

## Для кого и зачем

Для пользователя, которому нужно сохранить, отправить или распечатать отчёт о тратах за выбранный период.

## Что должно быть

- В блоке 02 есть две кнопки:
  - «Скачать Excel»;
  - «Сохранить PDF».
- В отчёт входят только траты, которые соответствуют активному фильтру списка.
- Для каждой траты в отчёте указываются:
  - дата;
  - категория;
  - комментарий;
  - сумма в тенге.
- В конце отчёта указывается итог выбранного периода.
- «Скачать Excel» создаёт CSV-файл в кодировке UTF-8 с разделителем `;`, который корректно открывается в Microsoft Excel.
- «Сохранить PDF» открывает отдельную печатную версию отчёта и вызывает системное окно печати браузера, где пользователь выбирает «Сохранить как PDF».
- Название отчёта содержит период или название активного фильтра и дату создания.
- Если видимых трат нет, кнопки не создают пустой отчёт и показывают понятную подсказку.

## Примеры

- Выбран фильтр «Неделя», видны три траты → Excel и печатный отчёт содержат эти три строки и их общую сумму.
- Выбран период «С» `01.11.2026`, «По» `10.11.2026` → отчёт содержит только траты с 1 по 10 ноября включительно.
- Выбран фильтр «Все» → в отчёт входят все сохранённые траты.
- За выбранный период трат нет → показана подсказка «Нет трат для отчёта».

## Ограничения

- Только HTML, CSS и JavaScript без библиотек и внешних ресурсов.
- Данные никуда не отправляются; файл формируется только в браузере.
- Из-за запрета библиотек Excel-отчёт создаётся в формате CSV, совместимом с Excel, а PDF сохраняется через системное окно печати браузера.
- Текст в CSV защищается от ошибочного распознавания формул Excel: значения, начинающиеся с `=`, `+`, `-` или `@`, должны сохраняться как обычный текст.
- Кнопки имеют размер не меньше 44px и удобны на ширине 375px.
- Скачивание не изменяет и не удаляет сохранённые траты.
- Существующие форма, фильтры, список и итоги не должны сломаться.

## Готово, когда

- Excel-совместимый CSV скачивается и содержит все видимые траты в правильных колонках.
- Кириллица и суммы корректно отображаются при открытии CSV в Excel.
- Печатная версия содержит заголовок, выбранный период, таблицу трат и итог.
- Из печатного окна отчёт можно сохранить в PDF.
- Оба отчёта используют тот же набор трат, что и видимый список.
- При отсутствии трат показывается подсказка и пустой файл не создаётся.
- После скачивания данные страницы остаются без изменений.
- Кнопки удобно использовать на ширине 375px.
