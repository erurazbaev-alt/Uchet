# Итог выбранного периода

## Для кого и зачем

Для пользователя, которому нужно сразу видеть общую сумму трат за выбранный в блоке 02 период.

## Что должно быть

- В блоке 02 появляется отдельная сумма с короткой подписью «ИТОГ».
- «ИТОГ» равен сумме всех трат, которые подходят под активный фильтр списка.
- Итог обновляется сразу после:
  - переключения периода;
  - изменения дат «С — По»;
  - добавления траты;
  - удаления траты.
- Для фильтра «Все» показывается сумма всех сохранённых трат.
- Для фильтров «День», «Неделя», «14 дней» и «Месяц» учитываются те же записи, которые видны в списке.
- Для корректного произвольного периода учитываются траты между датами «С» и «По» включительно.
- Если произвольный диапазон не заполнен или указан неверно, фильтр не применяется и «ИТОГ» показывает сумму всех отображаемых трат.
- Существующий итог за текущий месяц и итоги категорий сохраняются и продолжают считаться за текущий месяц.

## Примеры

- В списке за неделю показаны траты `5 000 ₸`, `2 500 ₸` и `12 000 ₸` → «ИТОГ» равен `19 500 ₸`.
- Выбран фильтр «День», за сегодня трат нет → «ИТОГ» равен `0 ₸`.
- Выбран период с 1 по 10 ноября, внутри него две траты `3 000 ₸` и `7 000 ₸` → «ИТОГ» равен `10 000 ₸`.
- Выбран фильтр «Все» → «ИТОГ» равен сумме всех сохранённых трат независимо от месяца.

## Ограничения

- Сумма отображается целыми тенге с пробелами между тысячами.
- Нельзя показывать `NaN`.
- Итог не хранится отдельно в localStorage, а каждый раз рассчитывается из сохранённых трат.
- Интерфейс должен быть удобен на ширине 375px.
- Фильтрация списка, месячный итог и итоги категорий не должны сломаться.

## Готово, когда

- В блоке 02 видна подпись «ИТОГ» и сумма выбранного периода.
- Сумма равна сумме всех видимых записей списка.
- При переключении каждого готового периода результат обновляется без перезагрузки.
- При изменении корректного диапазона «С — По» результат обновляется без перезагрузки.
- После добавления или удаления траты результат сразу пересчитывается.
- При отсутствии трат показано `0 ₸`.
- После F5 итог правильно восстанавливается из сохранённых трат.
- Блок читаем на ширине 375px.
