# Привычки и цель на неделю

## Для кого и зачем

Для человека, который вместе с расходами хочет отмечать регулярные полезные действия и видеть, выполнена ли недельная цель по каждой привычке.

## Что должно быть

- На странице есть отдельный блок «Привычки», не смешанный со списком расходов.
- Можно добавить привычку с коротким названием и целью на неделю от 1 до 7 раз.
- Для каждой привычки показываются название, недельная цель и количество отметок за текущую календарную неделю.
- У каждой привычки есть кнопка «Отметить», которая добавляет одну отметку за сегодня.
- Одну привычку можно отметить не больше одного раза за один календарный день.
- Ошибочную отметку за сегодня можно отменить.
- Когда количество отметок достигает цели, рядом появляется надпись «Цель выполнена».
- После начала новой календарной недели счётчик начинается заново, но сама привычка и её цель сохраняются.
- Привычку можно удалить.
- Привычки и отметки сохраняются в localStorage и остаются после F5.

## Примеры

- Добавить привычку «Прогулка» с целью `5` раз в неделю → показано «0 из 5».
- Отметить «Прогулка» сегодня → показано «1 из 5», повторная отметка в тот же день не добавляется.
- Отметить привычку в пять разных дней текущей недели → показано «5 из 5» и «Цель выполнена».
- Цель `3`, отметок `5` → показано «5 из 3» и «Цель выполнена».
- Отменить сегодняшнюю отметку → счётчик уменьшается на один; если он стал меньше цели, надпись «Цель выполнена» исчезает.
- После перехода на следующую календарную неделю привычка остаётся, а счётчик новой недели равен нулю.

## Ограничения

- Только HTML, CSS и JavaScript без библиотек и внешних ресурсов.
- Название привычки обязательно, после удаления пробелов содержит не больше 40 символов.
- Пустое название и цель не от 1 до 7 не сохраняются; рядом показывается понятная подсказка.
- Неделя начинается в понедельник и заканчивается в воскресенье по местной дате пользователя.
- Данные хранятся только в браузере и никуда не отправляются.
- Кнопки и поля не меньше 44px, блок удобен на ширине 375px.
- Нельзя показывать `NaN`, отрицательный счётчик или дублировать отметку за один день.
- Существующие расходы, фильтры, итоги, отчёты и сохранение после F5 не должны сломаться.

## Готово, когда

- Можно добавить привычку с названием и недельной целью от 1 до 7.
- Привычка показывается со счётчиком вида «0 из 5».
- Кнопка добавляет не больше одной отметки за текущий день.
- Сегодняшнюю отметку можно отменить.
- При достижении цели появляется «Цель выполнена», а при уменьшении ниже цели исчезает.
- В новой неделе счётчик начинается заново без удаления привычки.
- После F5 привычки, цели и отметки восстанавливаются.
- Привычку можно удалить.
- Блок работает на ширине 375px и не ломает функции учёта расходов.
