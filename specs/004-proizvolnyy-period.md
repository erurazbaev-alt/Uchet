# Произвольный период

## Для кого и зачем

Для пользователя, которому нужно посмотреть траты не только за готовые периоды, но и за любой выбранный промежуток дат.

## Что должно быть

- В блоке выбора периода есть вариант «С — По».
- После выбора этого варианта появляются два поля даты:
  - «С» — начальная дата;
  - «По» — конечная дата.
- После заполнения обеих дат список показывает траты внутри выбранного периода, включая начальную и конечную даты.
- Если одна из дат не заполнена, фильтр не применяется и показывается понятная подсказка.
- Если дата «С» позже даты «По», фильтр не применяется и показывается подсказка.
- Готовые фильтры «День», «Неделя», «14 дней», «Месяц» и «Все» продолжают работать.
- Произвольный фильтр меняет только список. Общий итог и итоги по категориям по-прежнему считаются за текущий месяц.

## Примеры

- «С» `01.11.2026`, «По» `10.11.2026` → показаны траты с 1 по 10 ноября включительно.
- Трата от `01.11.2026` и трата от `10.11.2026` входят в результат.
- «С» `10.11.2026`, «По» `01.11.2026` → список не фильтруется, показана подсказка о порядке дат.
- Заполнена только дата «С» → список не фильтруется, показана просьба выбрать обе даты.

## Ограничения

- Только HTML, CSS и JavaScript без библиотек и внешних ресурсов.
- Поля и кнопки имеют размер не меньше 44px.
- Блок должен быть удобен на экране шириной 375px.
- Выбранные даты не изменяют и не удаляют сохранённые траты.
- Существующие добавление, удаление, готовые фильтры и итоги не должны сломаться.

## Готово, когда

- Можно указать начальную и конечную даты произвольного периода.
- Список показывает только траты между этими датами включительно.
- Неполный или обратный диапазон не применяется и сопровождается понятной подсказкой.
- Переключение на любой готовый период скрывает произвольный диапазон и применяет выбранный фильтр.
- Общий итог и итоги категорий остаются итогами текущего месяца.
- Произвольный период удобно выбирать на ширине 375px.
